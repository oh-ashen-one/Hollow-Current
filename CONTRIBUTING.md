# Contributing

Open an issue describing the map, build version, input device, what you expected, and what happened. A short recording is particularly useful for blocked interactions, navigation, and Count encounters.

Use a topic branch, preserve Unity `.meta` files, and run the relevant checks listed in the README. Do not commit Unity caches, generated builds, credentials, private account exports, or third-party assets without redistribution rights. Record the origin and license of any new media.

Changes to gameplay, scene generation or shaders require fresh prepared scenes and lighting receipts before a release build. Test with ordinary player controls and normal damage; an invulnerable scripted route is coverage, not a difficulty or usability verdict.

Keep the approved Fish Audio performances intact unless an issue specifically calls for replacing them. Do not run legacy speech generators over the current voice files.
